\section{Sequences, series, and limits}
\subsection{Sequence Convergence Definition}
A sequence \(\seq{a}{n}\) is said to converge to a limit \(L\), if \(\forall\,\varepsilon>0\) there exists an \(N\in\mathbb{N}\) such that \(\forall\,n\in\mathbb{N}\) with \(n\geq N\) there holds: 
\[|a_n-L|<\varepsilon\]
We write \(a_n\to L\) as \(n\to \infty\) or \(\lim_{n\to\infty}a_n=L\)
\subsubsection*{Example}
\[a_n=\frac{1}{\sqrt{n}}\]
We want to show \(a_n\to 0\) as \(n\to\infty\). Let \(\varepsilon>0\). Define \(N=\lfloor \frac{1}{\varepsilon^2}\rfloor+1\). Then for \(n\geq N\):
\[|a_n-0|=\frac{1}{\sqrt{n}}\leq\frac{1}{\sqrt{N}}<\varepsilon\]
\[\blacksquare\]
\subsubsection{Convergence to \(\infty\)}
A sequence \(\seq{a}{n}\) converges to \(\infty\) if \(\forall K\in\mathbb{R}\) there exists \(N\in\mathbb{N}\) such that \(\forall n\geq N\) there holds \(a_n>K\). We write \(a_n\to\infty\) as \(n\to\infty\).
\subsection{Convergence of Reciprocals}
Let \(\seq{a}{n}\) be a sequence. If \(a_n>0,\ \forall n\in\mathbb{N}\), then \(a_n\to 0\iff \frac{1}{a_n}\to\infty\) as \(n\to\infty\).
\subsection{Algebra of Limits}
Similar to Core Mathematics in Year 1, we will make great use of algebra of limits in problem solving. A quick recap is that for sequences \(\seq{a}{n}\) and \(\seq{b}{n}\) with \(a_n\to a\) and \(b_n\to b\) as \(n\to \infty\) then we have the results:
\begin{itemize}
    \item \(a_n+b_n\to a+b\)
    \item \((a_n)(b_n)\to ab\)
    \item \(\frac{1}{a_n}\to\frac{1}{a}\) subject to some conditions: namely \(a_n\ne 0\) for all \(n\geq N\in\mathbb{N}\).
\end{itemize}
\subsection{Limits of Inequalities, Squeeze Theorem}
If \(\seq{a}{n}\) and \(\seq{b}{n}\) are sequences with \(a_n\leq b_n\) for all \(n\) and \(a_n\to a\), \(b_n\to b\) as \(n\to\infty\) then \(a\leq b\). If \(\seq{a}{n},\,\seq{b}{n}\) and \(\seq{c}{n}\) are sequences with \(a_n\leq b_n\leq c_n\) for all \(n\) such that \(a_n\to L\) and \(c_n\to L\) as \(n\to\infty\), then we also have \(b_n\to L\) as \(n\to \infty\).
\subsubsection*{Example}
Let \(\seq{a}{n}=\frac{2^n}{n!}\). Then we have:
\[0\leq \frac{2^n}{n!}\leq \frac{4}{n}\]
However we know that \(\frac{4}{n}\to 0\) as \(n\to\infty\), then by extension we have \(a_n\to 0\) as \(n\to \infty\) by the squeeze theorem.
\subsection{Ratio Test for Sequences}
Let \(\seq{a}{n}\) be a sequence with \(a_n\geq 0\) for all \(n\). Assume the sequence of ratios:
\[r_n=\frac{a_{n+1}}{a_n}\]
converges to \(q\in[0,\infty]\). We have the following result:
\[a_n\to\begin{cases}
    0 & 0\leq q<1 \\
    \infty & q>1 \\
    \text{indeterminate} & q=1
\end{cases}\]
\subsubsection{Proof for \(q>1\) case}
Let \(\seq{a}{n}\) be a sequence such that:
\[\frac{a_{n+1}}{a_n}\to q>1\]
Define a new value:
\[s=\frac{1+q}{2}\]
such that \(q>s>1\). Set:
\[\varepsilon=\frac{q-1}{2}>0\]
Then for \(n>N\) we have:
\[\left|\frac{a_{n+1}}{a_n}-q\right|<\varepsilon\]
\[\implies \frac{a_{n+1}}{a_n}>s>1\]
\[\implies \frac{a_n}{a_N}>s^{n-N}\]
\[\implies a_n>(a_Ns^{-N})s^n\]
So from squeeze theorem, we have \(a_n\to \infty\) as \(n\to \infty\).
\subsection{Standard Sequences}
These sequences should be remembered and can be quoted without proof in an exam. Let \(K\in\mathbb{Z}\) then we have the following results:
\[n^k\to\begin{cases}
    0 & k<0 \\
    1 & k=0 \\
    \infty & k>0
\end{cases}\]
Let \(q>0\):
\[q^n\to\begin{cases}
    0 & q<1 \\
    1 & q=1 \\
    \infty & q>1
\end{cases}\]
Let \(q\leq 0\):
\[q^n\to\begin{cases}
    0 & q>-1 \\
    \text{diverges} & \text{otherwise}
\end{cases}\]
Let \(0<q<1\) and \(K>0\):
\[n^kq^n\to 0,\quad n\to\infty\]
\subsubsection*{Example}
Let \(\seq{a}{n}\) be a sequence with:
\[a_n=\frac{2^n}{n!}\]
Then we have:
\[\frac{a_{n+1}}{a_n}=\left(\frac{2^{n+1}}{(n+1)!}\right)\left(\frac{n!}{2^n}\right)=\frac{2}{(n+1)}\to 0\text{ as }n\to\infty\]
\[\therefore \frac{2^n}{n!}\to 0\text{ as }n\to\infty\]
\subsection{Monotonicity}
A sequence \(\seq{a}{n}\) is called monotone increasing if for all \(n\in\mathbb{N}\), we have \(a_n\leq a_{n+1}\). It is called monotone decreasing if for all \(n\in\mathbb{N}\), we have \(a_n\geq a_{n+1}\). Constant sequences are monotone. Sequences like \((-1)^n\) are neither increasing nor decreasing. If \(a_n > 0\) for all \(n\) then \(\seq{a}{n}\) is monotone increasing if and only if \(a_{n+1}/a_n\geq 1\) for all \(n\).
\subsection{Supremum and Infimum}
Let \(A\subseteq \mathbb{R}\) be a non-empty set. If \(A\) is bounded above it has a least upper bound \(\sup A\in \mathbb{R}\). We have \(s=\sup A\) if:
\begin{align*}
    &\forall x\in A,\ x\leq s \\
    &\forall \varepsilon>0,\, \exists y\in A:\ y>s-\varepsilon
\end{align*}
If \(A\) is unbounded above, we write \(\sup A=+\infty\). If \(A\) is bounded below then it has a greatest lower bound \(\inf A\in\mathbb{R}\). We have \(l=\inf A\) if:
\begin{align*}
    &\forall x\in A,\ x\geq l \\
    &\forall \varepsilon>0,\, \exists y\in A:\ y<l+\varepsilon
\end{align*}
If \(A\) is unbounded below, we write \(\inf A=-\infty\). We set:
\begin{align*}
    &\sup \emptyset =-\infty \\
    &\inf \emptyset = +\infty
\end{align*}
For \(A\subseteq \mathbb{R}\) and \(A\ne\emptyset\), we have \(\inf A\leq \sup A\). If \(A\subseteq B\subseteq \mathbb{R}\) then \(\sup A\leq \sup B\) and \(\inf A \geq \inf B\). A monotone increasing sequence converges to it's supremum and a monotone decreasing sequence converges to it's infimum. A bounded monotone sequence always converges.
\subsection{Limit Points}
A number \(a\in\mathbb{R}\) is called a limit point or partial limit of the sequence \(\seq{a}{n}\) if \(\forall\varepsilon>0\) and \(\forall N\in\mathbb{N}\), \(\exists\, n\geq N\) such that:
\[|a_n-a|<\varepsilon\]
Note the key difference between this and the standard limit definition is that in the limit definition we require \(\forall\varepsilon>0, \exists N\in\mathbb{N}: \forall n\geq N\cdots\). Let \(\seq{a}{n}\) be a convergent sequence with limit \(L\). Then \(a\in\mathbb{R}\) is a limit point if and only if \(a=L\).
\subsubsection{Intuition}
For any property \(A(n)\), the statement: \(\forall N\in\mathbb{N}\) s.t. \(\exists n\geq N\) when \(A(n)\), is the same as saying there are infinitely many \(n\in\mathbb{N}\) for which \(A(n)\) holds.
\subsubsection*{Example}
Let \(\seq{a}{n}\) be a sequence with \(a_n=(-1)^n+\frac{1}{n}\). We claim the limit points are \(-1\) and \(1\). Let \(\varepsilon>0\) and let \(N\in\mathbb{N}\), then:
\[n=2\left(N+\left\lfloor\frac{1}{\varepsilon}\right\rfloor\right)+1\implies|a_n-(-1)|<\varepsilon\]
\[n=2\left(N+\left\lfloor\frac{1}{\varepsilon}\right\rfloor\right)\implies|a_n-1|<\varepsilon\]
\subsection{Subsequences}
Let \(\seq{a}{n}\) be a sequence and \(\seq{n}{k}\) be an increasing sequence of natural numbers. Then the sequence \(\seq{a}{{n_k}}\) is called a subsequence of \((a_n)\). For example:
\[\left(\frac{1}{n^2}\right)_n\ \text{is a subsequence of}\ \left(\frac{1}{n}\right)_n\]
\subsubsection{Limit points and subsequences}
Let \(\seq{a}{n}\) be sequence and \(a\in \mathbb{R}\). Then \(a\) is a limit point of \((a_n)\) if and only if there is a subsequence \(\seq{a}{{n_k}}\) that converges to \(a\). This is proved via the squeeze theorem. Additionally, let \(\seq{a}{n}\) be a sequence then \(a_n\) has a subsequence with \(a_{n_k}\to\infty\) as \(k\to\infty\) if and only if \(a_n\) is unbounded from above. Similarly for \(a_{n_k}\to-\infty\) if \(a_n\) is unbounded from below
\subsection{\(\limsup\) and \(\liminf\)}
Let \((a_n)_{n\geq p}\) be a sequence. Set \((b_m):=\sup_{k\geq m}a_k\) then \((b_m)_m\) is a decreasing sequence. Similarly \(c_m:=\inf_{k\geq m}a_k\) is an increasing sequence. Let \((a_n)_{n\geq p}\) be a sequence. We define:
\[\limsup_{n\to\infty}a_n:=\inf_{m\geq p}\sup_{k\geq m}a_k\]
\[\liminf_{n\to\infty}a_-n:=\sup_{m\geq p}\inf_{k\geq m}a_k\]
\subsubsection*{Example}
If \(\seq{a}{n}\) is such that \(a_n=(1+\frac{1}{n})(-1)^n\). Then:
\[a_n=\left(-2,\frac{3}{2},-\frac{4}{3},\frac{5}{4},-\frac{6}{5},\dots\right)\]
Then from our above definition:
\[b_n=\left(\frac{3}{2},\frac{3}{2},\frac{5}{4},\frac{5}{4},\dots\right)\]
\[c_n=\left(-2,-\frac{4}{3},-\frac{4}{3},-\frac{6}{5},\dots\right)\]
\[\limsup_{n\to\infty}a_n=\lim_{n\to\infty}b_n=1\]
\[\liminf_{n\to\infty}a_n=\lim_{n\to\infty}c_n=-1\]
You can think of this like looking at progressively smaller sets of the sequence starting at index \(0\), and then going to index \(1\) and so on, and then taking the supremum or infimum of the resulting set.
\subsubsection{Bounded sequences}
Let \(\seq{a}{n}\) be a bounded sequence. Then \(L^-=\liminf_{n\to\infty}a_n\) and \(L^+=\limsup_{n\to\infty}a_n\) are limit points of \(a_n\). The sequence \(\seq{a}{n}\) is bounded from above if and only if \(\limsup_{n\to\infty}a_n<\infty\), and likewise for bounded from below.
\subsection{Bolzano-Weierstra\ss}
Every bounded sequence has a convergent subsequence.
\subsection{Maximums and Minimums}
Let \(\seq{a}{n}\) be a bounded sequence. Let \(L=\liminf_{n\to\infty}a_n\) and \(M=\limsup_{n\to\infty}a_n\), then for any \(\varepsilon>0\), there are only finitely many \(n\in\mathbb{N}\) with \(a_n<L-\varepsilon\) or \(a_n>M+\varepsilon\). In particular \(L,M\) are the smallest and largest points of \(a_n\) respectively.
\subsection{Cauchy Sequences}
A sequence \(\seq{a}{n}\) of real numbers is called a Cauchy sequence if \(\forall \varepsilon>0,\ \exists N\in\mathbb{B}:\ \forall n,m\geq N\),
\[|a_n-a_m|<\varepsilon\]
Notice that this definition does not require any information about the location of the sequence and it does not require any particular limit. For example \(a_n=2^{-n}\) is a Cauchy sequence.
\subsubsection{Properties of Cauchy sequences}
\begin{itemize}
    \item Every convergent sequence is a Cauchy sequence.
    \item Every Cauchy sequence is bounded.
    \item Every Cauchy sequence in \(\mathbb{R}\) has a limit in \(\mathbb{R}\).
\end{itemize}
\subsubsection{Completeness}
A set \(A\) is called complete is every Cauchy sequence in \(A\) has a limit in \(A\).
\subsection{Series}
\subsubsection*{Revision}
Recall that series are just the sequence of partial sums and their limit if it exists:
\[\sum^\infty_{k=m}a_k:=\left(\sum^n_{k=m}a_k\right)_n\]
Recall some of the common series and their convergence:
\begin{align*}
    &\sum^\infty_{k=0}q^k=\frac{1}{1-q} && |q|\leq 1 \\
    &\sum^\infty_{k=0}\frac{x^k}{k!}=\exp(x) && x\in\mathbb{R} \\
    &\sum^\infty_{k=1}\frac{1}{k^p}=\zeta(p)&&p>1 \text{ converges, } p\leq1 \text{ diverges} 
\end{align*}
In the case of the zeta series, note that when \(p=1\) we have the harmonic series.
\subsection{Convergence Criteria of Series}
Immediately we know that if the sequence \(a_k\) does not tend to \(0\) then the series:
\[\sum^\infty_{k=0}a_k\]
diverges. A series \(\sum^\infty_{k=m}a_k\) is convergent if and only if for every \(\varepsilon>0\) there is an \(N\in\mathbb{N}\) such that for all \(p,n\geq N\) we have:
\[\left|\sum^p_{k=n}a_k\right|<\varepsilon\]
This is equivalent to saying that the sequence of partial sums is a Cauchy sequence. We say that a series is absolutely convergent if:
\[\sum^\infty_{k=m}|a_k|\]
converges. An absolutely convergent series is convergent.
\subsection{Comparison Theorem for Series}
If \(0\leq a_k\leq b_k\) and \(\sum^\infty_{k=m}b_k\) converges, then \(\sum^\infty_{k=m}a_k\) converges also. Additionally the contrapositive is often a very useful statement: If \(\sum^\infty_{k=m}a_k\) diverges then \(\sum^\infty_{k=m}b_k\) also diverges.
\subsubsection*{Example}
Does the series:
\[\sum^\infty_{k=1}\frac{\sin k}{3^k}\]
converge? First the \(\sin k\) term is quite unpleasant because it can be positive or negative, so we can take the absolute value. Once we have done this we notice that it is also bounded, and using this fact we can force it less than a known converging sequence. Hence by comparison theorem and absolute convergence, the original series converges.
\[\sum^\infty_{k=1}\left|\frac{\sin k}{3^k}\right|\leq \sum^\infty_{k=1}\left|\frac{1}{3^k}\right|\]
\subsection{Root Test for Series}
Let \((a_n)_n\) be a sequence and \(a=\limsup_{n\to\infty}(|a_n|)^{\frac{1}{n}}\in[0,\infty]\). If \(a<1\) then \(\sum^\infty_{k=m}a_k\) is absolutely convergent. If \(a>1\) then \(\sum^\infty_{k=m}a_k\) diverges. This \(\limsup_{n\to\infty}\) always exists.
\subsubsection*{Example}
\[\sum^\infty_{n=1}nq^n\]
\[(n\cdot|q|^n)^\frac{1}{n}=|q|\cdot n^\frac{1}{n}\to |q|\]
\[\limsup_{n\to\infty}(n\cdot|q|)^\frac{1}{n}=|q|\]
Hence this series converges for \(|q|<1\) and diverges for \(|q|\geq 1\). 
\subsection{Rules for Convergence for Power Series}
If \(F(x)=\sum^\infty_{k=0}b_kx^k\) is a power series and \(L=\limsup_{n\to\infty}|b_n|^\frac{1}{n}\) then:
\[L=\infty\implies F(x)\text{ converges only for }x=0\]
If \(0<L<\infty\), then set \(R=\frac{1}{L}\). \(F(x)\) converges for \(|x|<R\) and diverges for \(|x|>R\). if \(L=0\) then \(F(x)\) converges for all \(x\in\mathbb{R}\). The number \(R\) is called the minimum convergence of \(F\).
